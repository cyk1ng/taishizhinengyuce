# 配网调度业务量智能预测系统 - 需求文档

## 1. 项目概述

### 1.1 项目背景
配网调度业务量智能预测系统是基于多源数据融合和人工智能技术的智能决策支持系统。该系统旨在帮助电力调度部门预测未来业务量趋势，优化人员配置，提高调度效率，降低运营风险。

### 1.2 项目目标
- **智能化预测**：基于历史数据和多因素分析，准确预测未来调度业务量
- **科学决策**：提供人员配置建议和排班方案，优化资源配置
- **风险管控**：实时识别业务量异常和潜在风险，提供预警
- **数据可视化**：通过直观的仪表盘和图表，展示业务态势

### 1.3 目标用户
- 配网调度中心管理人员
- 值班调度员
- 业务分析人员
- 系统运维人员

## 2. 功能需求

### 2.1 核心功能模块

#### 2.1.1 数据融合分析
**功能描述**：整合多源数据，为预测和决策提供数据基础

**输入数据**：
- 历史调度记录（业务量、工单类型、处理时长）
- 天气数据（温度、降水量、风力、极端天气）
- 节假日信息（工作日/休息日/节假日）
- 设备状态（重过载、缺陷、故障）
- 人员排班信息

**输出数据**：
- 标准化融合数据集
- 数据质量报告
- 特征工程结果

#### 2.1.2 业务量预测
**功能描述**：基于 AI 模型预测未来调度业务量

**预测维度**：
- 时间维度：今日、未来 7 天、未来 30 天
- 业务类型：计划工作量、非计划工作量
- 工单类型：周计划、设备投退、跳闸故障、缺陷处理、重过载、保供电

**预测方法**：
- LLM 智能分析（基于大语言模型）
- 时序模型（ARIMA、Prophet 等）
- 多因素回归分析

**输出结果**：
- 预测业务量数值
- 置信区间
- 趋势分析
- 影响因素权重

#### 2.1.3 人员决策支持
**功能描述**：基于业务量预测生成人员配置建议

**决策内容**：
- 建议值班人数
- 人员技能匹配
- 加班/调休建议
- 临时借调建议

**决策依据**：
- 预测业务量
- 当前在值人数
- 人员技能标签
- 历史工作效率

#### 2.1.4 智能排班
**功能描述**：生成科学合理的排班方案

**排班规则**：
- 公平性原则（工作量均衡）
- 连续性原则（避免频繁换班）
- 技能匹配原则（关键岗位技能要求）
- 法规合规原则（劳动法规定）

**排班输出**：
- 早/中/晚班排班表
- 值班长安排
- 休息人员安排
- 排班公平性报告

#### 2.1.5 工作量统计
**功能描述**：实时统计和展示工作量数据

**统计维度**：
- 计划工作量：周计划、设备投退、保供电、检修业务、方式单
- 非计划工作量：跳闸故障、异常缺陷、重过载
- 时间维度：实时、日、周、月

**展示方式**：
- 卡片式汇总（总数、开展中、已终结）
- 柱状图（各模块业务情况）
- 饼图（操作票情况）
- 折线图（各阶段工作量趋势）
- 环形图（网络发令情况）

#### 2.1.6 风险预警
**功能描述**：识别业务量异常和潜在风险

**预警类型**：
- 业务量过载预警
- 人员不足预警
- 设备风险预警
- 天气影响预警

**预警级别**：
- 高风险（红色）：立即处理
- 中风险（橙色）：关注处理
- 低风险（绿色）：正常监控

#### 2.1.7 智能问答
**功能描述**：通过 AI 对话界面，自然语言查询和分析数据

**问答能力**：
- 数据查询（"今天有多少计划工作量？"）
- 趋势分析（"最近 7 天业务量趋势如何？"）
- 原因分析（"为什么明天业务量会增高？"）
- 决策建议（"需要增加值班人员吗？"）

**交互方式**：
- 文本输入
- 快速操作按钮（今日预测、7 天预测、人员建议、风险预警）
- 流式响应

### 2.2 用户界面需求

#### 2.2.1 主仪表盘
**布局结构**：
- 顶部导航栏：系统标题、刷新按钮、柔性值班计算按钮、时钟
- 核心数据卡片区（5 张卡片）：
  - 计划工作量（总数、开展中、已终结）
  - 非计划工作量（总数、开展中、已终结）
  - 当值班组（班组名称、人数）
  - 人员配置（建议人数、超负荷状态）
  - 天气状况（温度、降水量、风力、极端天气）
- 快速操作区（4 个按钮）：今日预测、7 天预测、人员建议、风险预警
- 风险预警卡片（3 条预警信息）
- 今日待办卡片（待办事项列表）
- 图表区（4 个图表）：
  - 各模块业务情况（柱状图）
  - 操作票情况（饼图）
  - 各阶段业务工作量（折线图）
  - 网络发令情况（环形图）
- AI 对话区（聊天界面）

#### 2.2.2 弹窗功能
**计划工作量详情弹窗**：
- 3 个输入框：计划检修、设备投退、周计划
- 保存按钮

**非计划工作量详情弹窗**：
- 2 个输入框：跳闸故障、异常缺陷、重过载
- 保存按钮

**值班人员详情弹窗**：
- 第一行：当值班组、值班时间、班次、建议人数、超负荷
- 班次筛选：晚班、早班、中班
- 班组筛选：A班、B班、C班、D值、E班
- 当值人员列表（姓名、角色、操作按钮）
- 休息人员列表（姓名、角色、操作按钮）
- 搜索功能

**风险预警详情弹窗**：
- 预警列表（级别、标题、描述）
- 关闭按钮

**今日待办弹窗**：
- 待办列表（状态、标题、描述）
- 关闭按钮

**向量知识库弹窗**：
- 搜索框
- 文档列表
- 添加文档按钮

**天气详情弹窗**：
- 天气信息编辑表单
- 保存按钮

## 4. 接口需求

### 4.1 后端 API

#### 4.1.1 工作量看板
- **接口**：`GET /api/workload_dashboard`
- **参数**：`target_date`（目标日期）
- **返回**：工作量汇总数据、图表数据

#### 4.1.2 计划工作量详情
- **接口**：`GET /api/plan_workload_detail`
- **参数**：`target_date`（目标日期）
- **返回**：各分类详情数据

#### 4.1.3 非计划工作量详情
- **接口**：`GET /api/nonplan_workload_detail`
- **参数**：`target_date`（目标日期）
- **返回**：各分类详情数据

#### 4.1.4 人员详情
- **接口**：`GET /api/staff/detail`
- **参数**：`team_name`（班组名称）、`date_str`（日期）
- **返回**：班组详情、当值人员、休息人员

#### 4.1.5 风险预警
- **接口**：`GET /api/risk_alerts`
- **返回**：风险预警列表

#### 4.1.6 今日待办
- **接口**：`GET /api/todos`
- **返回**：待办事项列表

#### 4.1.7 AI 对话
- **接口**：`POST /api/chat`
- **参数**：`message`（用户消息）、`thread_id`（会话 ID）
- **返回**：流式 AI 响应

## 5. 部署需求

### 5.1 环境要求
- **操作系统**：Linux（推荐 Ubuntu 20.04+）或 Windows 10+
- **Docker**：Docker Desktop 4.0+ 或 Docker Engine 20.10+
- **内存**：>= 8GB
- **磁盘**：>= 50GB

### 5.2 外部依赖
- **Oracle 数据库**：11g+（可选，支持假数据模式）
- **Ollama**：本地模型服务（可选，支持云端模型）
- **火山引擎**：云端模型服务（可选）

### 5.3 配置文件
- `.env`：环境变量配置
- `config/agent_llm_config.json`：本地模型配置
- `config/agent_llm_config_docker.json`：Docker 模型配置
